# controle-fila-impressoras

## Descrição do Problema

Lançamentos de impressoras com fila de espera e prioridade de urgência.

## Requisitos

- Registrar impressoras com fila e prioridade.
- Ordenar por prioridade e depois por fila.
- Exibir as 3 primeiras da fila.

## Exemplo de Uso

Entrada:

[{'id': 'IMP01', 'fila': 2, 'prio': 1}, {'id': 'IMP02', 'fila': 1, 'prio': 2}, {'id': 'IMP03', 'fila': 3, 'prio': 1}]


Saída:

IMP01
IMP03
IMP02
